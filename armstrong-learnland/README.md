# LearnLand - Early Literacy Adventure App Prototype

## Overview
LearnLand is an interactive ELA and literacy adventure app designed for Pre-K through 2nd Grade learners. It focuses on letter sounds, sight words, CVC word blending, story comprehension, and simple sentence construction.

## Features
- Ocean & Sky design theme with soft rounded cards and child-friendly touch targets.
- Playful "Ms. Rachel" style voice synthesis and audio playback.
- Interactive Avatar Creator & Dressing Room with earnable accessory unlocks.
- 5 Literacy Isles Quests (Phonics, Sight Words, Blending, Story, Sentences).
- Learner Creative Studio (Drawing canvas & sticker storybuilder).
- Parent & Educator Progress Dashboard with printable summary report.

## How to Run
1. Unzip `learnland-static-website.zip`.
2. Open `index.html` directly in any web browser (Chrome, Safari, Firefox, Edge).
3. No Node.js, server, API key, or database required!
