# LearnLand - Early Literacy Adventure App Prototype

## Overview
LearnLand is a complete, presentation-ready educational prototype designed for Pre-K, Kindergarten, and 1st-2nd Grade learners. It helps children develop fluency, reading comprehension, sight word recognition, CVC sound blending, and simple sentence construction through guided adventure quests.

## Key Features & Pedagogical Design
- **Ocean & Sky Visual Theme:** Soft rounded geometry, high WCAG AA contrast colors, large touch targets, and image-rich visual anchors.
- **Natural Auto-Speech Narration:** Powered by browser SpeechSynthesis tuned to a warm, conversational cadence (0.98x rate, 1.18 pitch) for early non-readers.
- **5 Active Literacy Isles Quests:**
  1. Phonics Isle (Letter sounds & initial phonemes)
  2. Sight Word Cave (High-frequency words)
  3. Blending Forest (CVC phoneme sound tiles & word blending)
  4. Story Kingdom (Character, setting, & event clues)
  5. Sentence Builder Studio (Construct simple sentences)
- **Learner Progress & Parent Summary:** Real-time skill mastery percentages and printable summary report (`window.print()`).
- **Interactive Companion Avatar:** Earnable accessory unlocks (Crowns, Captain Hats, Star Glasses).

## How to Run
1. Unzip `learnland-final-static-website.zip`.
2. Open `index.html` directly in any web browser (Chrome, Safari, Firefox, Edge).
3. No Node.js, npm, database, server, or API key required! Everything runs client-side inside the browser.
