ABOUT SCHOLAR SLEUTH

Reading can be an investigation.

Scholar Sleuth is a focused course prototype for grades 6–8. It turns reading skills into a mystery challenge so learners practice finding evidence, making inferences, and explaining their thinking.

How it works

  1. Read the evidence.
  2. Choose the answer that best fits the clues.
  3. Use feedback to rethink an incorrect answer.
  4. Track your progress as you solve.

Accessibility

Text stays visible alongside speech. Buttons are keyboard-friendly and clearly labeled. Speech uses the browser's built-in SpeechSynthesis API when available and never replaces written content.
