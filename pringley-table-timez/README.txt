Table Timez — static educational prototype
Open index.html in a modern web browser. No Node, npm, server, database, or API key is required.
Progress is stored locally in the browser with localStorage. Data is fictional/local only.
Audio uses the browser's built-in speech synthesis as the temporary fallback described in the build package.
Demonstration: Home → Learn it → answer a fact → My Table → learn enough facts to unlock Practice/Timed Test → Achievements → About & Help.
