# Wordy Wonders

A self-contained static educational web prototype for Kindergarten through Grade 2 literacy practice.

## Run
Open `index.html` in a modern browser, or serve the folder with any static web server.

## Verify
1. Select Kindergarten, Grade 1, or Grade 2.
2. Try Picture Words, Rhyming Words, and Mixed Practice.
3. Complete a 5-question round and verify feedback, points, streaks, and progress.
4. Visit Resources, My Progress, and About & Help.
5. Use the speaker buttons to test browser Device Voice. Audio remains optional.

No external APIs, accounts, or sensitive learner data are used.
